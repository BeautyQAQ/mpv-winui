## 再生成

在 Windows 上使用 PowerShell 7 和系统自带 `System.Drawing`，无需安装 Pillow、Cairo 或其他图片依赖：

```powershell
pwsh -NoProfile -File build/branding/generate-brand-assets.ps1
```

脚本读取 SVG 中相同的多边形及颜色，分别以目标尺寸的 4 倍渲染后缩小，生成 PNG 以及包含多个 PNG 图层的 ICO。每个尺寸直接从矢量坐标生成，不由小图逐层放大。可指定 `-SourceSvg` 和 `-OutputDirectory` 作独立输出；默认写回品牌目录。该脚本只支持当前母版使用的实色多边形，遇到未支持的 SVG 元素或属性会报错，避免修改母版后静默丢失图形。

SVG 为可编辑的母版；调整多边形或颜色后运行上述命令，并一同提交 SVG、PNG、ICO 与脚本。运行生成脚本不是应用构建的一部分，普通构建和发布使用仓库已有资源，不要求开发者安装额外绘图工具。
