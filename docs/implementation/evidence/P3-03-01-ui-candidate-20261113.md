## 1. 来源与环境

本轮将系统主题、图标控制条和链接 Flyout 纳入独立候选，补齐当前 UI 的回归、有限连续测试、最终目录 GUI、主题检查及发布登记。产品源码未修改，来源为干净 `main / 2d44dbd822e565640a1e94bba5bb3c8160e73b0c`，`sourceDirty=false`。原 11 月 5 日 `28ffe46` 候选不含本次 UI，其包和源码快照保持冻结；后补本篇及其他入口文档也不回写新包冻结的源码 ZIP。

实际环境为 Windows 11 专业版 `10.0.26300`、RTX 3070 / 驱动 `32.0.16.2124`，系统报告 3840×2160、120 Hz；环境中另有 GameViewer 虚拟显示适配器，不将本轮描述为无人远程连接的独占物理显示测试。构建 SDK `10.0.404`、PowerShell `7.6.9`，候选为 Release `win-x64`、.NET `10.0.15` 与 Windows App SDK 自包含。详见 `baseline/environment.json`、包内 `build-info.json` 与首轮便携启动器环境记录。

`pre-seal-verification.json` 确认冻结源码 305 个文件、194 项构建输入及 23 处媒体/清单哈希匹配。实际候选应用 DLL SHA-256 为 `2E937F6C9733C8D06842C9B0D589C8D1030939667DB7B3A51A0265AAF9053F84`。普通构建、候选 DLL 测试和最终目录 GUI 分别保存身份，不把历史包结果当作本包复验。

## 6. 支持范围与已知限制

- **平台与交付：** Windows x64 的进程内 libmpv / ANGLE / D3D11 / WinUI 3 自包含候选；本轮实测 Windows 11 `10.0.26300`、RTX 3070 / `32.0.16.2124`。工程 `TargetPlatformMinVersion=10.0.17763.0` 是构建声明，不是 Windows 最低版本或全部驱动实机认证；ARM64、安装器/签名、商店及自动更新不在本次交付范围。
- **现有功能：** 本地文件、HTTP/HTTPS 直链、基础 HLS、播放控制、倍速、时间轴数字预览、音量/静音、轨道、媒体信息、全屏、最近记录和系统主题 UI；具体本轮 GUI 与自动化范围以上述结果为准。既有基础 HLS/字幕验收限于 HTTP VOD、H.264/AAC MPEG-TS、MKV 内嵌 SRT/ASS，未泛化为所有 HLS、网络认证、加密分片或字幕格式，见 [P1-04 限制](P1-04-01-video-hls-subtitles-and-media-information.md#6-限制与后续)。
- **性能与颜色：** 本轮功能和像素用例不新增真实显示吞吐、长期流畅度或物理 HDR 准确性结论。GUI 的 2/8 呈现丢帧保留；既有 GTX 1060 / UU 首轮 23/24、窗口 2/3 达标及尖峰按用户接受完成，不改写为每轮全部达标，也不重开该调查，见 [接受登记](P3-01-02-gtx1060-uu-remote-performance.md#6-用户接受与完成登记)。
- **旧 Intel：** HD 4600 设备范围已收口。HEVC 硬解及软件 4K60 性能按既有用户决定不适用；H.264 1080p60 波动和呈现丢帧作为限制保留，不另列设备待办。既有结果未验证 NVIDIA 940M 独显路径，本轮也未执行新包旧设备复验，见 [完成登记](P3-00-06-940m-gui-and-h264-acceptance.md#本设备完成登记)。
- **暂缓/未验证：** 两小时长测和资源趋势继续暂缓；真实触屏、系统触控取消、跨屏/双显示器、额外 DPI/硬件、真实驱动重置与 HDR 仪器测量未因本轮候选而通过或新增为阻塞。窄窗未在本轮重测，历史 UI 检查见 [11 月 5 日记录](../ui-refresh-20261105.md)。
- **范围外功能：** 播放列表、媒体库、自适应码率产品策略、时间轴缩略图和外部字幕检索/下载未纳入本轮。
