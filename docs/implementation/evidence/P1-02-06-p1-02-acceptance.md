# P1-02 验收汇总：状态、错误与命令契约

- 日期：2026-10-16。
- 范围：按 [Phase 1 计划](../phase-1-plan.md#4-工作包细则) 中 P1-02 的验收条目汇总各轮可复核结论；不重复执行已验证内容，不改写各记录的限制。
- 依据：[P1-02-01 加载取消边界](P1-02-01-load-cancellation-boundary.md)、[P1-02-02 事件积压与播放列表跳转](P1-02-02-event-overflow-and-redirect.md)、[P1-02-03 错误契约与 UI 派发](P1-02-03-error-contract-and-ui-dispatch.md)、[P1-02-04 seek 与请求契约](P1-02-04-seek-and-request-contract.md)、[P1-02-05 跨加载归属审计](P1-02-05-cross-load-attribution.md)。

| 计划验收条目 | 结论与依据 |
|---|---|
| UI 不依赖 mpv 原始属性名、指针或原生结构；状态与错误有明确唯一来源 | 满足：应用只经抽象层与后端事件读取状态与错误（P1-02-03 的 UI 有界派发与错误契约）；本轮新增的原生结构（`MpvEventStartFile`、`MpvEventCommand`）仅为 Native 内部类型，不进入抽象层 |
| 连续加载、seek 竞争、命令等待取消/超时、EOF 重播和加载失败后恢复行为符合契约；取消等待不被误记为撤销已进入 core 的命令 | 满足：P1-02-01（提交前/后取消边界）、P1-02-04（seek 回复顺序、请求取消/超时、连续加载媒体归属）、P1-02-05（跨加载条目归属） |
| 缓冲结束不会因队列丢弃或迟到事件永久丢失；旧媒体事件不覆盖新媒体状态 | 满足：P1-02-02（有界队列补偿与 redirect）、P1-02-05（等待期旧 StartFile / EndFile 归属校验，修复前失败与修复后通过均保留） |
| 不可恢复终态拒绝播放修改，迟到成功回复不能清除错误；日志区分加载、播放、渲染和初始化错误，并保留诊断原因和 URL 脱敏 | 满足：P1-02-03（错误分类与非渲染终态保护）、P1-02-04（迟到回复不能清除新媒体错误）；日志分类与 URL 脱敏在 P1-02-01～03 已落地并由回归覆盖 |
| 仅补实际缺口，已有回归能覆盖的行为引用现有证据，不增加仅镜像实现的测试 | 满足：各轮均先定向复现再修复或明确“未复现不宣称修复”（如请求契约 7 项在请求行为未修改时通过、探针压力通过项保留为回归） |

**必要验证**：Abstractions、LibMpv、App 相关状态/命令测试已随全量回归执行；涉及真实事件次序的变更（本轮）由全量回归中的 P1-01 固定素材原生集成在 x64 Debug/Release 下复核。最终结果：两种配置各 285 通过、0 失败、5 跳过（跳过均为未配置素材或性能输入），日志与 TRX 在 `artifacts/p1-02-attribution/`。

**结论与限制**：P1-02 在计划声明范围内满足全部验收条目，进度表标记通过。关闭不改变各记录的限制：未做 GUI 人工验收、未重新发布；性能（PERF-02）、页面生命周期、视频 HLS/字幕与最终发布分别由 P1-03～P1-05 及跟进项处理。
