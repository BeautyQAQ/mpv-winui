## 1. 当前结论

Phase 0 已在声明范围内通过，正式路线和基础实现继续沿用。Phase 1 的目标是生产级播放基础：固化现有模块、控制与状态契约、资源所有权、生命周期、媒体覆盖和发布流程。完整 UI、倍速交互、最近打开持久化等产品工作不自动进入本阶段。

本轮已建立六个工作包，P1-00 文档、基线与产物入口核对通过。P1-01 已开始：固定素材清单、性能场景清单、判定规则与测量工具已进入仓库；2026-09-22 在远程连接的 SDR 开发机上完成 Debug/Release 构建，两种配置各通过 14 项统计测试和 1 项测量链路自检。所有性能场景尚未在目标机执行，PERF-01/PERF-02 仍为待验证。其余工作包均未开始；已有实现是可承接的输入，不代表这些工作包已经通过。

## 5. 待复核项与延后范围

### 本阶段待复核

- **PERF-01：历史应用内慢帧。** [2026-09-11 恢复记录](evidence/buffering-and-app-recovery-2026-09-11.md#整段播放结果与未解决的性能问题)曾记录 GTX 1060、4K60 SDR tone-map 约 14 fps，尚缺同场景当前版本的关闭证据。P1-01 已定义场景 S1/S1-D/S1-S/S1-R/S2/S7 与判定规则，待执行；不能据此断言当前仍有同一缺陷，也不能用 RTX 3070 PQ 输出结果直接关闭。已知需要对照的变量：该轮为 Debug 应用（默认带 D3D11 调试层）且带间隔像素读回。
- **PERF-02：原生功能报告中的掉帧。** 本轮 HEVC/AV1 的 105/110 次呈现掉帧来源于功能测试报告（前 60 帧后在渲染线程反复 Render + 读回）。P1-01 已定义场景 S4/S5 做"有采样 vs 无采样"对照，待执行。未完成复核前不宣称性能通过。
- **MEDIA-01：媒体覆盖。** Phase 0 的 HLS 集成为 ADTS AAC 分片，P1-04 补视频 HLS；轨道状态测试不替代字幕真实呈现。
- **LIFE-01：页面生命周期。** 已有同一 core 上的原生上下文恢复证据，P1-03 核对实际页面卸载、重新挂载与关闭竞态。

### 沿用原决定延后

跨屏/双显示器、长期稳定性、真实触屏、100%/125%/200% DPI、Intel/AMD 等额外硬件矩阵以及 HDR 仪器测量继续保留为未验证。它们不成为本阶段新增阻塞，也不由自动化结果推断通过。Windows/驱动支持声明必须与实际验证范围一致。

最近打开持久化、倍速交互、时间轴预览、完整字幕面板和 OSD/触屏视觉交互留待 Phase 2。播放列表、自适应码率策略等若拟加入，先明确产品范围，不能仅因出现在 Phase 0 后续输入中便当作本阶段已承诺功能。
