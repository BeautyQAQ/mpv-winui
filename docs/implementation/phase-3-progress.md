同日因旧候选 ZIP 未随 Git 到本机，从干净 `main / 18a85ab` 重新生成 `MpvShell-phase3-candidate-20261103-170050-5f9ed2`。发布与封包命令均退出 0，693 个 ZIP 文件条目、290 个源码文件及原生/许可/媒体核验通过。通过 Computer Use 从最终目录完成播放/暂停继续、停止重播、倍速、换片、最近记录无参重启恢复与不自动播放、正常退出；三轮均退出 0，补充轮覆盖播放中停止、换片和约 5.167/8 秒关闭，资源按序释放、用户历史已恢复。最终目录 GUI 缺口据此关闭，详见 [GUI 证据](evidence/P3-00-02-candidate-final-directory-gui.md)；旧候选身份和当时工具失败保留。

2026-11-03 在另一台 GTX 1060 开发机通过 UU 远程完成独立性能复测，产品和测试源码未变：固定 4K30 首轮 Debug 12/12、保留的旧 Release 11/12 达标，AV1 补充六次均达标但不覆盖首次 2 帧呈现丢帧；真实窗口三轮为 58.221 / 59.964 / 60.029 fps，首轮 27 帧呈现丢帧保留。相对旧 RDP 的长 Present 等待明显改善；窗口尺寸、Debug 二进制及运行时差异已分列，不能宣称唯一根因。Release Computer Use 的实际画面、暂停/继续、跳转、全屏/Esc 和正常退出通过，历史恢复。用户查看上述结果后明确接受并要求标记全部完成，P3-01 / PERF-02 本机调查据此收口，原始阈值和失败记录不变；见 [GTX 1060 / UU 调查及用户接受登记](evidence/P3-01-02-gtx1060-uu-remote-performance.md#6-用户接受与完成登记)。该轮不替代下述 940M/Intel 设备及候选目录验收。

10 月 28 日历史候选 `MpvShell-phase3-candidate-20261028-121903-72991b` 已生成并封包，包含当前 Phase 2 功能，产品源码未改动；694 个 ZIP 条目及 288 个源码快照文件逐项核验通过。当时 GUI 工具绑定窗口失败，只强制终止测试进程，未完成正常退出和重启验收，用户历史已恢复。这些是旧包历史；11 月 3 日新候选已补齐 GUI，但不关闭旧设备回归失败，不替代历史已通过的 Phase 1 包。

当前检出未包含 P2-05 原始汇总报告和登记的 Phase 1 ZIP，因此本轮不宣称已重新核验旧产物；其历史身份继续保留。本轮使用新生成的固定素材及独立报告，详见 [P3-00 记录](evidence/P3-00-01-baseline-and-candidate.md)。
