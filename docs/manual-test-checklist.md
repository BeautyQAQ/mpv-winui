# V1 手工验收清单

## 基础播放

- [ ] 能粘贴 HTTP 直链并开始播放
- [ ] 能粘贴 HTTPS 直链并开始播放
- [ ] 能粘贴 m3u8 地址并开始播放

## 控件与手势

- [ ] 点击/轻触视频区域可呼出控件
- [ ] 空闲约 3 秒后控件自动隐藏
- [ ] 底部时间轴支持拖拽定位
- [ ] 横向拖动可触发 seek

## 面板与信息

- [ ] 可打开 OSD 面板
- [ ] 可打开字幕/音轨面板并切换轨道
- [ ] 可打开详细信息面板并显示 HDR/编码摘要
- [ ] 最近 URL 列表按最近使用顺序去重展示

## 错误与恢复

- [ ] 输入不可访问 URL 时出现用户可读错误提示
- [ ] 后端 mpv 进程异常退出时出现“后端连接已断开”提示
- [ ] 重新输入可用 URL 后错误提示可清空并继续播放

## 生命周期

- [ ] 关闭应用时 mpv 子进程会被清理
